# NEON FRONTIER

A mobile-friendly 2.5D/3D neon-city exploration prototype powered by Three.js.

## Run
Open `index.html` through GitHub Pages or a static web server. Three.js is loaded as an ES module from jsDelivr, so an internet connection is required.

## Controls
- **WASD / Arrow keys:** Move
- **Mouse drag:** Rotate camera
- **E:** Interact with the signal beacon
- **Touch:** Left virtual joystick + action buttons

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
